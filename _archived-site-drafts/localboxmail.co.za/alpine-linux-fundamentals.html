1. Why Alpine Linux?

Alpine Linux is a compact distribution designed around simplicity, security and small resource usage. It works well on Raspberry Pi systems where storage and memory are limited and where every installed component should have a clear purpose.

Important difference: Alpine normally uses OpenRC for service management, not systemd. Commands such as rc-service and rc-update replace many uses of systemctl.

3. Installation

Choose the correct Raspberry Pi image, verify the download, write it to the target storage, and boot with a console or network connection available. Alpine can run in diskless mode, data mode or sys mode. For a beginner server, a normal persistent installation is usually easier to understand.

setup-alpine
# Follow prompts for keyboard, hostname, interface,
# DNS, timezone, user, SSH and target disk.

4. Packages with apk

apk update                 # refresh package indexes
apk upgrade                # install available upgrades
apk add nginx curl git     # install packages
apk del git                # remove a package
apk info nginx             # show package information
apk search python3         # search available packages

The package database records what was installed and which files belong to each package. Avoid copying random binaries into system directories when a maintained package is available.

5. Services with OpenRC

rc-service nginx start
rc-service nginx status
rc-service nginx restart
rc-service nginx stop
rc-update add nginx default
rc-status

rc-service controls a service now. rc-update controls whether it starts automatically in a runlevel. This distinction is similar to starting a systemd service versus enabling it.

6. Users and permissions

adduser peter
addgroup peter wheel
id peter
ls -l /srv/www
chown -R nginx:nginx /srv/www
chmod 750 /srv/www

Run network services under dedicated, unprivileged accounts. Grant only the file and device access each service needs.

7. Networking and SSH

ip addr
ip route
cat /etc/network/interfaces
rc-service networking restart
apk add openssh
rc-update add sshd default
rc-service sshd start

Before exposing SSH outside the local network, use key authentication, disable unnecessary accounts and restrict firewall access.

8. Example: install Nginx

apk update
apk add nginx
mkdir -p /var/www/localbox
printf '%s\n' '<h1>LocalBox on Alpine</h1>' > /var/www/localbox/index.html
rc-update add nginx default
rc-service nginx start
ss -tulpn | grep ':80'
curl http://127.0.0.1

The web root and virtual-host configuration may differ by package version. Read the installed configuration before changing it, then test the configuration before restarting the service.

9. Suggested exercises

  1. Install a package, inspect it with apk info, and remove it.
  2. Start a service without enabling it, reboot, and explain what happens.
  3. Create an unprivileged account for a Go service.
  4. Use ss and curl to verify Nginx locally before testing from another machine.
  5. Compare the Alpine OpenRC commands with equivalent Debian systemd commands.
