How it works

The process is meant for groups: choose a name, agree who will manage it, confirm the setup, then publish the shared site and mail service.

1. Choose a name Check a new domain or tell us about one already used by the group.
2. Confirm responsibility A coordinator or trusted contact is identified for access, updates, and approvals.
3. Configure the service Domain, DNS, email, website, and contact form are configured on a LocalBox Raspberry Pi host.
4. Share access The responsible person or group receives login details and can publish information for their audience.

Why this setup is different

LocalBox uses small, low power Raspberry Pi hardware so a person, practice, group, or organisation can run useful online services without the cost, heat, noise, and power needs of a normal server.

5V and ~2.5A DC

Easily integrate with small UPS, battery, inverter, or solar-backed power.

Low heat and quiet

A Raspberry Pi class setup does not need the same cooling as a desktop or rack server, and it can run quietly in a studio, school, office, clinic, or shared room.

Small enough to place anywhere

The computer board is about the size of a bank card, so it can be placed in a small case, cabinet, or hosted shelf without needing a server room.

Affordable hardware

A Raspberry Pi 3 class board can cost under R1000 before storage, power, case, and setup, which keeps the starting point realistic for small hosted services.

Built for shared responsibility

The domain, email, website, and data can be managed for an artist, school, NGO, project, cooperative, clinic, church, company, or local group instead of being tied to one person's laptop.

Simple to replace and back up

The setup can use mounted storage and planned backups, making it easier to recover or replace the device than a large custom server.
