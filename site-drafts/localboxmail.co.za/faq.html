FAQ

Questions about LocalBox Mail

Short answers about the three LocalBox options, new .za domain orders, first mailboxes, payments, website setup, and support.

What domains can I register through LocalBox right now?

LocalBox is starting with new South African .za domain registrations. We currently focus on new domain orders such as .co.za, with transfers, existing-domain moves, and international domains planned for later.

What happens after I pay for a domain?

After payment is verified, LocalBox can register the domain with Domains.co.za, create the Cloudflare zone, set the Cloudflare nameservers at the registrar, and add the route for the LocalBox host.

DNS propagation can take time. The order is handled in stages so each step can be checked before moving on.

What are the three LocalBox options?

The simple choices are: LocalBox hosts your domain and email, LocalBox hosts your Raspberry Pi, or LocalBox prepares a full Raspberry Pi package and couriers it to you.

Case, storage, courier, extra mailboxes, migration, backup, and support can be added where needed.

Can I host the LocalBox myself?

Yes, if you order the complete package we will set up the Raspberry Pi and courier it to you.

Plug it into your local network and it should find an IP address and work out the box.

Do I need to continue with the monthly hosting or can I move it to another provider?

It is your domain and you can move it to another provider if you wish.

You can also park the domain with us for no cost.

Will I get an email address with the domain?

The order form asks for the first email address, usually something like info@example.co.za. LocalBox can create that first receiving mailbox after the domain certificate step.

Outbound sending setup is kept separate and manual for now, because sending-domain reputation and spam control need careful handling.

Why is Brevo or outbound sending manual?

Receiving mail and sending mail are different risks. We can create a receiving mailbox on LocalBox, but outbound sending can affect domain reputation if it is misused.

For now, LocalBox will confirm any Brevo or sending-domain setup separately before enabling it.

Where do I log in to mail and admin?

After the first mailbox is created, the customer receives the mailbox username, domain, temporary password, and direct links by email.

The mailbox login is normally https://yourdomain.co.za/login. The domain admin page is normally https://yourdomain.co.za/admin.

Can I change the temporary mailbox password?

Yes. After signing in to the mailbox, use the password page to change the temporary password. Domain admins can also reset mailbox passwords from the admin page.

Can I cancel my monthly subscription?

You can cancel your subscription at any stage.

Your domain will become inactive and parked with us until you decide what you want to do next.

Can I edit the website after it is live?

Yes. A domain admin can use the LocalBox page tools to upload or edit HTML pages. The starter website is only the first published page.

Does LocalBox replace normal hosting?

LocalBox is a practical small-site, mail, and domain setup built around Raspberry Pi hosts and Cloudflare routing. It is intended for local projects, small organisations, schools, portfolios, and similar sites that need a simple managed presence.
